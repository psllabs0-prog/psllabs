Use this worksheet **after locating the report for the material you are reviewing**. It is a record-keeping aid, not a substitute for the original laboratory file or your laboratory's receiving procedure.

Need help finding a file? Start with [finding a PSL batch report](/science/third-party-testing-explained). Need to authenticate the document? Use the [worked laboratory-report verification guide](/guides/verify-peptide-laboratory-report).

## Keep the supplied label and report as separate records

The label identifies what was supplied and its nominal amount. The report records results for the submitted sample. Preserve both; do not edit a measured result to make it match a label.

Keep a photo or transcription of the supplied product name, SKU, batch identifier and nominal vial amount with the original report. If a code is missing or the identifiers differ, record that gap and ask PSL to clarify the connection. A product SKU alone is not proof of a lot match.

Read the [product-label disclosures](/disclaimer#product-label-information) when reviewing the affected materials.

## Fields for your receiving record

- **Receipt:** date received, product and SKU, supplied label amount, physical form and package condition.
- **Lot connection:** label or package batch identifier; report batch field; any supplier explanation needed to connect them.
- **Report source:** laboratory name, task or report number, original file location and date you accessed it.
- **Analysis:** sample-received and analysis dates where the report supplies them.
- **Results:** exact result label, value and unit for each relevant measurement; the laboratory's comments.
- **Scope:** tests named on the document and any missing result or method detail required by your work.
- **Follow-up:** question asked, answer received, source of that answer and whether the issue remains open.

Save the full file with these notes. A spreadsheet cell containing only a purity number loses the context needed to interpret it later.

## Do not rename a result while copying it

A percentage, an amount in milligrams and a concentration are separate measurements. A nominal label amount is also a separate field. Copy each with its original label and unit.

For example, our [purity-versus-amount guide](/guides/peptide-purity-vs-content) compares published GHK-Cu, Tesamorelin and solution report fields. The examples belong to their named samples and reports; they are not a shared specification for all PSL products.

If your record template has no place for a reported concentration or a laboratory comment, add a field or keep the information in notes. Do not force the value into a misleading column.

## Record gaps explicitly

“Not reported on this file” and “confirmed by the laboratory” mean different things. Keep that distinction visible. A missing test on one document does not establish that it was never performed, and a high purity value does not answer the missing question.

For a label/report difference, preserve both values and the original source. Do not replace the report with a newer file for another lot. For an unreadable field, request the complete file rather than guessing.

## Keep the record connected to the material

Store the report with the receiving record for that lot and retain the relevant link or file reference when material is moved within your laboratory. Follow your own document-control and storage procedures.

The [storage-and-stability guide](/guides/peptide-storage-stability) covers records to request and handling notes to retain. The [testing-scope guide](/guides/what-peptide-testing-can-establish) explains why a chemical report does not establish every property of a material.

For help with PSL documentation, [contact support](/contact) with the product, batch code and task number. Send order references privately.
