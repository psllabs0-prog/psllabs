Use this page when you need to locate a **PSL report file**, or when a file or lot match is missing. For report authenticity and interpretation, follow the linked guides rather than treating a successful lookup as a complete verification.

## Start with the identifiers you have

Visit [Batch Reports](/coa). The lookup accepts a **task number or batch name**, such as the examples shown beside the search field. Copy the identifier from the original report or supplied packaging, including letters and punctuation.

A product name helps you find the relevant [product page](/products), but it does not uniquely identify a production lot. A SKU or nominal vial size should not be substituted for a batch identifier.

## Open the full document

The product page's batch-documentation section and [Batch Reports](/coa) link to the published original files. Open the report image or PDF and check that its task number and batch field are readable.

Keep the full file, including headers, comments and verification information. A cropped screenshot or a listing's retyped result is a pointer to documentation, not the complete record.

Once you find the file, the [receiving worksheet](/science/how-to-read-a-coa) shows which fields to retain.

## If the lookup returns no match

Check that you entered a task number or batch name rather than an order number, SKU or product strength. Then try the identifier shown on the complete original document.

If no file matches, [contact PSL support](/contact). Include:

- The product name and nominal label amount.
- The supplied batch code, or say that no code is readable.
- The task number if you have one.
- Which page or link you tried, and what happened.

For an existing order, share its order reference privately. Do not post personal shipping or payment information in public comments.

No published match means the documentation question is unresolved. It is not permission to use a similarly named report from another lot.

## If the file opens but the identifiers do not match

Compare the supplied package identifier with the report's batch field. If they differ, ask for a documented connection between them. Keep the original identifiers in your records until the difference is resolved.

The [batch-specific versus generic COA guide](/guides/batch-specific-vs-generic-coa) explains the difference between a sample-specific result and a general specification. The [product disclosures](/disclaimer#product-label-information) describe known label/report issues on affected PSL products.

## If the laboratory verification link fails

Use the laboratory's own instructions. Janoshik's [official verification form](https://janoshik.com/verification/) requires a task number and unique key from the report. A mistyped or incomplete entry does not, by itself, establish that a document is false.

If the lab record is unavailable or differs from your file, ask the issuing laboratory or PSL to resolve the issue. Do not mark the report verified merely because the PSL download works.

The [worked verification guide](/guides/verify-peptide-laboratory-report) covers this step in detail. Report verification and linking that report to the supplied material are separate checks.

## What finding a file establishes

Finding the document gives you a source to review. It does not establish that every vial is identical, that unlisted tests were performed, or that a product is approved for human or animal use.

Review the [testing page](/testing) for PSL's published scope and the [guides](/guides) for measurement explanations. Materials are for laboratory research only.
